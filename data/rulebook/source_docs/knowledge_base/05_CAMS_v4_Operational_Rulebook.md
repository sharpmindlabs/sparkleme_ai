# 05_CAMS_v4_Operational_Rulebook

CAMS AI KNOWLEDGE BASE v4.0  OPERATIONAL RULEBOOK  AI EXECUTION SPECIFICATION  PURPOSE  This document converts CAMS methodology into operational rules for another AI system.  Each rule defines:  -   what must happen,  -   when it applies,  -   what evidence is required,  -   what behaviour is prohibited,  -   how decisions are affected.  Excluded:  -   client cases  -   client images  -   historical outcomes  -   unavailable calibration examples  ==================================================  RULE GROUP 1   —   CORE AI OPERATING RULES  ==================================================
RULE CAMS - 001: CASE RESET RULE  Purpose:  Ensure every analysis begins independently.  Trigger:  Every new analysis.  Required Action:  Reset previous conclusions, predictions, expectations, and outcomes.  Forbidden:  Using previous cases to influence current decisions.  Decision Impact:  Any contaminated analysis must restart.  --------------------------------------------------  RULE CAMS - 002: EVIDENCE ONLY RULE  Purpose:  Maintain evidence integrity.  Required Evidence:  Approved drape evidence only.
Forbidden:  Using:  -   hair colour unless provided  -   Fitzpatrick unless provided  -   assumptions  -   stereotypes  -   expected results  Decision Impact:  Unsupported evidence invalidates reasoning.  --------------------------------------------------  RULE CAMS - 003: TRUE PALETTE NEUTRALITY RULE  Purpose:  Prevent automatic True palette selection.  Required Action:  Treat all candidates equally.  Forbidden:  "True" palette wins because it is True.  Decision Impact:  Winner requires CAMS evidence.
==================================================  RULE GROUP 2   —   WORKFLOW RULES  ==================================================  RULE CAMS - 010: HOME SEASON GATE RULE  Purpose:  Separate Home Season from Flow.  Required:  Complete Home Season before Flow.  Forbidden:  Using Flow results to determine Home Season.  --------------------------------------------------  RULE CAMS - 011: PAIRWISE INDEPENDENCE RULE  Purpose:  Prevent comparison contamination.  Required:  Every comparison begins neutral.  Forbidden:  Importing previous pairwise outcomes.
--------------------------------------------------  RULE CAMS - 012: REVERSE VERIFICATION RULE  Purpose:  Confirm comparison stability.  Required:  Repeat comparison in reverse order.  Decision Impact:  Unresolved differences require review.  ==================================================  RULE GROUP 3   —   SEVEN CAMS CHECK RULES  ==================================================  RULE CAMS - 020: FACIAL DETAILS RULE  Evaluate:  -   under - eye effects  -   eye socket effects  -   cheek hollows  -   mouth corners  -   nasolabial effects  -   jaw effects
Required Distinction:  Healthy modelling versus unhealthy shadow.  Forbidden:  Rewarding added shadow as improvement.  --------------------------------------------------  RULE CAMS - 021: SKIN COLOUR RULE  Evaluate:  -   believable flesh colour  -   healthy colour activity  -   grey veil  -   white patches  -   yellow cast  -   redness pressure  Decision Impact:  Skin health has priority.  --------------------------------------------------  RULE CAMS - 022: SKIN CONSISTENCY RULE  Evaluate:
Whole - face pigmentation continuity.  Forbidden:  Confusing smoothness with improvement.  --------------------------------------------------  RULE CAMS - 023: JAWLINE RULE  Evaluate:  -   support  -   lift  -   heaviness  -   drag  --------------------------------------------------  RULE CAMS - 024: EYE RULE  Evaluate:  -   authority  -   animation  -   vitality  Forbidden:  Allowing eye authority alone to decide.
--------------------------------------------------  RULE CAMS - 025: FOCUS RULE  Mandatory hierarchy:  Eyes → Person → Colour  Forbidden:  Colour - first reasoning.  --------------------------------------------------  RULE CAMS - 026: BALANCE RULE  Evaluate:  -   integration  -   harmony  -   palette support  ==================================================  RULE GROUP 4   —   AUDIT RULES  ==================================================  RULE CAMS - 030: INDEPENDENT PHYSIOLOGY AUDIT  Trigger:
All close decisions.  Required:  Determine whether improvement is facial or visual only.  --------------------------------------------------  RULE CAMS - 031: EFFECT SOURCE SEPARATION RULE  Classify every advantage:  A. Physiological improvement  B. Palette - created effect  C. Uncertain  Only A receives strong decision weight.  --------------------------------------------------  RULE CAMS - 032: NATURAL LUMINOSITY AUDIT  Trigger:  Spring, Light, Brightness, luminosity conflicts.  Evaluate:  -   openness  -   sheen
-   eye vitality  -   colour activity  --------------------------------------------------  RULE CAMS - 033: GREY VEIL AND SUPPRESSION AUDIT  Trigger:  Muted, Summer, softer palette conflicts.  Evaluate:  Harmony versus suppression.  --------------------------------------------------  RULE CAMS - 034: AUTHENTIC PIGMENTATION AUDIT  Trigger:  Warmth or Autumn conflicts.  Separate:  Authentic pigmentation from reflected colour.  --------------------------------------------------  RULE CAMS - 035: SHADOW REDUCTION AUDIT
Trigger:  Physiology boundaries.  Evaluate:  Reduced unhealthy shadow while preserving anatomy.  --------------------------------------------------  RULE CAMS - 036: WARMTH SOURCE AUDIT  Trigger:  Spring versus Autumn decisions.  Determine:  Authentic warmth versus colour concentration.  --------------------------------------------------  RULE CAMS - 037: VITALITY VS GROUNDING AUDIT  Trigger:  Vitality/depth conflicts.  Separate:  Vitality from richness and grounding.  --------------------------------------------------
RULE CAMS - 038: BIOLOGICAL ANIMATION AUDIT  Trigger:  Bright competitions.  Bright may win only through genuine animation.  ==================================================  RULE GROUP 5   —   FLOW RULES  ==================================================  RULE CAMS - 050: FLOW EQUAL CANDIDATE RULE  All Flow candidates begin equal.  No default True advantage.  --------------------------------------------------  RULE CAMS - 051: WINTER FLOW RULES  Candidates:  True Winter, Cool, Bright, Deep  Requirements:
Cool:  Must provide physiology benefit, not clarity alone.  Bright:  May win through biological animation.  Deep:  Must preserve structure without heaviness.  --------------------------------------------------  RULE CAMS - 052: SUMMER FLOW RULES  Candidates:  True Summer, Cool, Light, Muted  Light:  Must show physiological improvement.  Cool:  Definition requires verification.  Muted:  Requires suppression audit.  --------------------------------------------------
RULE CAMS - 053: SPRING FLOW RULES  Candidates:  True Spring, Warm, Light, Bright  Warm:  Requires authentic warmth.  Light:  Requires physiology improvement.  Bright:  Requires genuine vitality.  --------------------------------------------------  RULE CAMS - 054: AUTUMN FLOW RULES  Candidates:  True Autumn, Warm, Muted, Deep  Warm:  Requires independent benefit.  Muted:  Requires identity preservation.
Deep:  Requires structure without drag.  ==================================================  RULE GROUP 6   —   FINALIZATION RULES  ==================================================  RULE CAMS - 060: FINAL AUDIT RULE  Before final result:  Complete:  -   seven - check review  -   closest competitor review  -   required audits  -   bias checks  --------------------------------------------------  RULE CAMS - 061: RUNNER - UP RULE  Runner - up must be neighbouring palette only.  --------------------------------------------------  RULE CAMS - 062: BOUNDARY WORDING RULE
Use only genuine boundaries.  Required format:  "True [palette] moving slightly toward [bridge]"  ==================================================  RULE GROUP 7   —   AI FAILURE PREVENTION  ==================================================  The AI must reject:  -   automatic True palette selection  -   structure - only decisions  -   smoothness - only decisions  -   brightness - only decisions  -   warmth - only decisions  -   previous case transfer  -   skipped audits  -   unsupported conclusions  ==================================================  TRANSFER VALIDATION  Included:  YES Core rules
