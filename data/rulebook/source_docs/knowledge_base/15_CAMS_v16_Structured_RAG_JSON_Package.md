# 15_CAMS_v16_Structured_RAG_JSON_Package

CAMS AI KNOWLEDGE BASE v16.0  STRUCTURED RAG / JSON KNOWLEDGE PACKAGE  TECHNICAL AI INGESTION SPECIFICATION  PURPOSE  This document defines how CAMS AI knowledge should be structured for ingestion into another AI  platform using:  -   RAG systems  -   vector databases  -   structured knowledge bases  -   rule engines  -   agent memory systems  This document does not add new methodology.  It converts existing CAMS knowledge into machine - oriented structures.  Excluded:  -   client cases  -   client images  -   historical outcomes  -   unavailable calibration examples  ==================================================  1. KNOWLEDGE OBJECT MODEL
==================================================  Each CAMS knowledge unit should contain:  Knowledge_ID  Category  Name  Purpose  Trigger  Instructions  Forbidden Behaviour  Required Evidence  Required Audits  Decision Impact  Related Knowledge  Version
Status  ==================================================  2. KNOWLEDGE CATEGORIES  ==================================================  Core Rule  Workflow Rule  CAMS Check  Audit Rule  Boundary Rule  Flow Rule  Decision Rule  Prompt Rule  Failure Prevention Rule  Validation Rule
==================================================  3. CORE RULE OBJECTS  ==================================================  CASE_RESET_RULE  Category:  Core Rule  Purpose:  Prevent contamination from previous analyses.  Trigger:  Every new analysis.  Instructions:  -   reset prior conclusions  -   evaluate current evidence only  Forbidden:  -   using previous outcomes  -   using expected answers  Decision Impact:  Contaminated analysis requires restart.  --------------------------------------------------
EVIDENCE_ONLY_RULE  Category:  Core Rule  Purpose:  Maintain evidence integrity.  Required:  Approved drape evidence.  Forbidden:  -   unsupported assumptions  -   hair information unless supplied  -   Fitzpatrick unless supplied  --------------------------------------------------  TRUE_PALETTE_NEUTRALITY_RULE  Category:  Bias Prevention Rule  Purpose:  Prevent automatic True palette preference.
Instruction:  All palettes must earn selection through CAMS evidence.  ==================================================  4.
