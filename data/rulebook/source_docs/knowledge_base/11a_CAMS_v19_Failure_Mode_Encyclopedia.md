# 11a_CAMS_v19_Failure_Mode_Encyclopedia

CAMS AI KNOWLEDGE BASE v19.0  FAILURE MODE ENCYCLOPEDIA  AI ERROR PREVENTION SPECIFICATION  PURPOSE  This document extracts the common reasoning failures a CAMS AI system must prevent.  The purpose is to teach the AI:  -   what mistakes occur,  -   why they occur,  -   how to correct them,  -   which audits prevent them.  Excluded:  -   client cases,  -   client images,  -   historical outcomes,  -   unavailable calibration libraries.  ==================================================  1. FAILURE PREVENTION PRINCIPLES  ==================================================  CAMS decisions must be based on:
-   physiological improvement,  -   facial harmony,  -   eye/person hierarchy,  -   evidence - based audits.  The AI must not rely on:  -   visual drama,  -   stereotypes,  -   palette reputation,  -   simple aesthetic preference.  ==================================================  2. PALETTE BIAS FAILURES  ==================================================  FAILURE:  True palette automatically wins.  Why it happens:  The AI assumes the True palette represents the ideal.  Correction:  True palettes are candidates only.  Required:
Evaluate through CAMS evidence.  Audit:  True Palette Neutrality Audit.  --------------------------------------------------  FAILURE:  Winter wins because it looks stronger.  Why it happens:  The AI confuses contrast with improvement.  Correction:  Separate:  -   healthy definition  from  -   unhealthy shadow.  Audit:  Shadow versus Modelling Audit.  --------------------------------------------------  FAILURE:  Summer wins because it looks smoother.
Why it happens:  The AI confuses smoothness with harmony.  Correction:  Determine whether smoothness is:  -   true integration,  -   or suppression.  Audit:  Suppression Audit.  --------------------------------------------------  FAILURE:  Spring wins because it looks brighter.  Why it happens:  The AI confuses brightness with vitality.  Correction:  Brightness must prove:  -   eye vitality,  -   facial openness,  -   healthy colour activity.  Audit:  Natural Luminosity Audit.
--------------------------------------------------  FAILURE:  Autumn wins because it looks richer.  Why it happens:  The AI confuses richness with health.  Correction:  Depth and warmth must improve the person.  Audit:  Authentic Pigmentation Audit.  ==================================================  3. COLOUR - FIRST REASONING FAILURES  ==================================================  FAILURE:  The drape colour is judged instead of the person.  Correction:  Always apply:  Eyes → Person → Colour
Question:  Does the person improve?  Not:  Does the colour look impressive?  ==================================================  4. VISUAL EFFECT CONFUSION  ==================================================  FAILURE:  A visible effect is treated as physiological improvement.  Examples:  -   stronger contrast,  -   brighter colour,  -   deeper colour,  -   smoother appearance.  Correction:  Apply Effect Source Separation.
Classify:  A. Physiological improvement  B. Palette - created effect  C. Uncertain  Only A receives strong decision weight.  ==================================================  5. SHADOW INTERPRETATION FAILURES  ==================================================  FAILURE:  All definition is considered good.  Correction:  Determine:  Healthy anatomical modelling  versus  Unhealthy shadow burden.
Check:  -   under - eyes,  -   sockets,  -   cheek hollows,  -   jaw,  -   facial information.  Audit:  Healthy Modelling vs Shadow Audit.  ==================================================  6. SMOOTHNESS INTERPRETATION FAILURES  ==================================================  FAILURE:  Smoothness automatically equals improvement.  Correction:  Ask:  Is the face healthier?  Or is information reduced?  Audit:
Grey Veil and Suppression Audit.  ==================================================  7. WARMTH INTERPRETATION FAILURES  ==================================================  FAILURE:  Warmth automatically equals healthy pigmentation.  Correction:  Separate:  Authentic pigmentation  from:  -   redness,  -   orange pressure,  -   reflected colour.  Audit:  Warmth Source Audit.  ==================================================  8. DEPTH INTERPRETATION FAILURES  ==================================================
FAILURE:  Depth automatically equals grounding.  Correction:  Separate:  Grounding  from:  -   heaviness,  -   drag,  -   reduced vitality.  Audit:  Vitality vs Grounding Audit.  ==================================================  9. BRIGHTNESS INTERPRETATION FAILURES  ==================================================  FAILURE:  Brightness automatically equals animation.  Correction:
Require:  -   eye animation,  -   facial openness,  -   person - first improvement.  Audit:  Biological Animation Audit.  ==================================================  10. SINGLE FEATURE DOMINANCE FAILURES  ==================================================  FAILURE:  One CAMS check determines the outcome.  Examples:  -   eyes alone,  -   jaw alone,  -   contrast alone,  -   skin smoothness alone.  Correction:  Use cumulative CAMS evidence.
Audit:  Cumulative Physiology Magnitude Audit.  ==================================================  11. WORKFLOW FAILURES  ==================================================  FAILURE:  Using Flow before Home Season.  Correction:  Home Season must be completed first.  --------------------------------------------------  FAILURE:  Carrying previous comparison results forward.  Correction:  Every comparison begins neutral.  Audit:  Pairwise Independence Rule.  --------------------------------------------------
FAILURE:  Skipping reverse verification.  Correction:  Repeat comparison from reverse order.  ==================================================  12. FINAL DECISION FAILURES  ==================================================  FAILURE:  Counting wins instead of evaluating magnitude.  Correction:  Use cumulative physiological evidence.  --------------------------------------------------  FAILURE:  Choosing a distant runner - up.  Correction:  Runner - up must be neighbouring palette.  --------------------------------------------------  FAILURE:
Using boundary wording for non - boundaries.  Correction:  Only use boundary language when genuinely close.  ==================================================  13. AI SELF - CHECK QUESTIONS  ==================================================  Before finalizing ask:  Did I choose this because it improves the person?  Did I confuse visual impact with physiology?  Did I complete required audits?  Did I favour a palette stereotype?  Did I preserve CAMS hierarchy?  ==================================================  TRANSFER AUDIT  Included:  YES palette failure prevention
