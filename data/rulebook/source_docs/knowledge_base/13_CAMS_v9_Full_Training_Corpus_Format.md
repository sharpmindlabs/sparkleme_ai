# 13_CAMS_v9_Full_Training_Corpus_Format

CAMS AI KNOWLEDGE BASE v9.0  FULL TRAINING CORPUS FORMAT  AI KNOWLEDGE RETRIEVAL SPECIFICATION  PURPOSE  This document restructures CAMS methodology into AI - retrievable knowledge units.  Designed for:  -   AI knowledge bases  -   RAG systems  -   structured retrieval systems  -   agent memory systems  The purpose is to allow another AI system to retrieve the correct CAMS rule at the correct moment.  Excluded:  -   client cases  -   client images  -   historical outcomes  -   unavailable calibration examples  ==================================================  KNOWLEDGE UNIT FORMAT  ==================================================
Each knowledge unit contains:  Knowledge ID  Category:  -   Core Rule  -   Workflow Rule  -   CAMS Check  -   Audit Rule  -   Boundary Rule  -   Flow Rule  -   Decision Rule  -   Failure Prevention Rule  Purpose  Trigger  Required AI Action  Required Evidence  Forbidden Behaviour  Decision Impact
Related Knowledge Units  ==================================================  CORE KNOWLEDGE CARDS  ==================================================  CARD: CAMS - CORE - 001  NAME:  Case Reset Rule  Category:  Core Rule  Purpose:  Prevent previous analysis contamination.  Trigger:  Every new analysis.  Required Action:  Treat every case as completely new.  Forbidden:  Using previous conclusions, outcomes, predictions, or expected answers.  Decision Impact:  Contaminated analysis must restart.
--------------------------------------------------  CARD: CAMS - CORE - 002  NAME:  Evidence Only Rule  Category:  Core Rule  Purpose:  Maintain evidence integrity.  Required Evidence:  Approved drape evidence only.  Forbidden:  -   unsupported assumptions  -   hair colour unless supplied  -   Fitzpatrick unless supplied  -   stereotypes  Decision Impact:  Unsupported evidence cannot influence results.  --------------------------------------------------
CARD: CAMS - CORE - 003  NAME:  True Palette Neutrality Rule  Category:  Bias Prevention Rule  Purpose:  Prevent automatic True palette preference.  Required Action:  Evaluate every palette as an equal candidate.  Forbidden:  Selecting a True palette because it is True.  ==================================================  CAMS CHECK KNOWLEDGE CARDS  ==================================================  CARD: CAMS - CHECK - 001  NAME:  Facial Details  Purpose:  Evaluate facial response.
Observe:  -   under - eye effects  -   eye socket effects  -   cheek hollows  -   mouth corners  -   nasolabial areas  -   jaw effects  Critical distinction:  Healthy modelling versus unhealthy shadow.  Forbidden:  Rewarding added shadow as improvement.  --------------------------------------------------  CARD: CAMS - CHECK - 002  NAME:  Skin Colour  Observe:  -   believable flesh colour  -   healthy colour activity  -   grey veil  -   white patches  -   yellow/sallow cast  -   redness pressure
Decision Impact:  Skin health has priority.  --------------------------------------------------  CARD: CAMS - CHECK - 003  NAME:  Skin Consistency  Observe:  Whole - face pigmentation continuity.  Forbidden:  Confusing smoothness with physiological improvement.  --------------------------------------------------  CARD: CAMS - CHECK - 004  NAME:  Jawline  Observe:  -   support  -   lift  -   heaviness  -   drag
--------------------------------------------------  CARD: CAMS - CHECK - 005  NAME:  Eyes  Observe:  -   authority  -   animation  -   vitality  Forbidden:  Allowing eye impact alone to determine outcome.  --------------------------------------------------  CARD: CAMS - CHECK - 006  NAME:  Focus Hierarchy  Required hierarchy:  Eyes → Person → Colour  Forbidden:  Colour - first reasoning.
--------------------------------------------------  CARD: CAMS - CHECK - 007  NAME:  Balance and Harmony  Observe:  -   integration  -   support  -   palette dominance  ==================================================  AUDIT KNOWLEDGE CARDS  ==================================================  CARD: CAMS - AUDIT - 001  NAME:  Independent Physiology Audit  Trigger:  Close comparisons. -   shadow burden  -   skin quality  -   continuity  -   vitality  --------------------------------------------------  CARD: CAMS - AUDIT - 002  NAME:  Effect Source Separation  Purpose:  Separate true improvement from visual effects. Uncertain  Decision Impact:  Only physiological improvement receives strong weight.  --------------------------------------------------

CARD: CAMS - AUDIT - 005  NAME:  Authentic Pigmentation Source Audit  Trigger:  Warmth and Autumn boundaries.
