# 03_CAMS_v2_Encyclopedic_Training_Manual

CAMS AI KNOWLEDGE BASE v2.0  ENCYCLOPEDIC TRAINING MANUAL  AI KNOWLEDGE TRANSFER DOCUMENT  PURPOSE  This document is designed to train another AI system on the CAMS colour analysis methodology.  It transfers:  -   CAMS reasoning framework  -   workflow rules  -   seven - check system  -   audits  -   boundary safeguards  -   validation rules  -   anti - bias controls  It does not include:  -   client cases  -   client images  -   individual outcomes  -   unavailable calibration libraries  The AI must learn CAMS rules, not memorize results.
==================================================  PART 1   —   CAMS FOUNDATION  ==================================================  CAMS is a structured drape - based colour analysis methodology.  The AI must analyse only approved evidence.  The AI must ignore:  -   previous conclusions  -   previous predictions  -   expected answers  -   answer pages  -   highlighted answers  -   historical outcomes  Every analysis begins as a new case.  Do not use:  -   hair colour unless explicitly provided  -   Fitzpatrick unless explicitly provided  -   external assumptions  -   stereotypes  ==================================================  PART 2   —   PALETTE SYSTEM  ==================================================
Approved Home Seasons:  Winter  Summer  Spring  Autumn  Approved Flow Palettes:  True Winter  True Summer  True Spring  True Autumn  Cool  Warm  Bright  Light  Deep  Muted  True palettes are equal candidates.  No palette receives automatic preference.  ==================================================  PART 3   —   CAMS INTERPRETATION HIERARCHY
==================================================  Mandatory hierarchy:  Eyes → Person → Colour  The AI must prioritize:  1. Healthy facial response  2. Eye vitality and authority  3. Person - first harmony  4. Colour relationship  A visually dramatic palette does not automatically indicate improvement.  ==================================================  PART 4   —   COMPLETE WORKFLOW  ==================================================  PHASE 1: HOME SEASON  Required comparisons:  Winter vs Summer  Winter vs Spring  Winter vs Autumn  Summer vs Spring
Summer vs Autumn  Spring vs Autumn  Every comparison requires:  1. Neutral starting point.  2. Independent observation of Palette A.  3. Independent observation of Palette B.  4. Seven CAMS check comparison.  5. Reverse - order verification.  6. Reconciliation.  The AI must not:  -   import earlier comparisons,  -   use Flow expectations,  -   count wins mechanically.  Final Home Season requires:  -   bridge validation,  -   physiology audit,  -   cumulative evidence review.  PHASE 2: FLOW  Only begins after Home Season.  All candidates must be evaluated equally.
==================================================  PART 5   —   SEVEN CAMS CHECKS  ==================================================  CHECK 1: FACIAL DETAILS  Observe:  -   under - eye effects  -   eye socket effects  -   cheek hollows  -   mouth corners  -   nasolabial areas  -   jaw effects  Critical rule:  Healthy modelling is different from unhealthy shadow.  Do not reward added shadow.  CHECK 2: SKIN COLOUR  Observe:  Positive:  -   believable flesh colour
-   healthy colour activity  Negative:  -   grey veil  -   white patches  -   washed appearance  -   yellow/sallow cast  -   excessive redness  CHECK 3: SKIN CONSISTENCY  Observe:  -   whole - face pigmentation continuity  Do not confuse:  -   suppression with refinement  -   smoothness with improvement  CHECK 4: JAWLINE  Observe:  -   lift  -   support  -   heaviness  -   drag  CHECK 5: EYES
Observe:  -   authority  -   animation  -   vitality  Eye strength cannot override complexion decline.  CHECK 6: FOCUS  Use:  Eyes → Person → Colour  CHECK 7: BALANCE/HARMONY  Observe:  -   integration  -   support  -   whether the palette dominates the person  ==================================================  PART 6   —   AUDIT LIBRARY  ==================================================  INDEPENDENT PHYSIOLOGY AUDIT
Purpose:  Determine whether a palette creates genuine facial improvement.  Review:  -   shadow reduction  -   colour quality  -   continuity  -   vitality  EFFECT SOURCE SEPARATION  Every advantage must be classified:  1. Physiological improvement  2. Palette - created effect  3. Uncertain  NATURAL LUMINOSITY AUDIT  Trigger:  Spring, Light, or luminosity competition.  Evaluate:  -   facial openness  -   natural sheen  -   eye vitality  -   healthy colour activity
GREY VEIL AND SUPPRESSION AUDIT  Evaluate:  -   true harmony  -   reduced facial information  -   false smoothness  AUTHENTIC PIGMENTATION AUDIT  Separate:  -   authentic pigmentation  -   reflected colour  -   redness  -   yellow/orange pressure  COMPLEXION PHYSIOLOGY PRIORITY AUDIT  Before finalization check:  -   shadow burden  -   continuity  -   believable flesh colour  -   sick appearance  -   grey/white veil  -   yellow cast  ==================================================
PART 7   —   BOUNDARY KNOWLEDGE  ==================================================  WINTER BOUNDARIES  Winter cannot win only because of:  -   contrast  -   structure  -   authority  Winter vs Summer:  Require healthy definition verification.  Winter vs Spring:  Run physiology - first analysis.  Spring may win through:  -   healthy colour activity  -   luminosity  -   reduced shadow.  Winter vs Autumn:  Audit:  -   colour pressure  -   pigmentation  -   heaviness.
SUMMER BOUNDARIES  Summer cannot win only because of:  -   smoothness  -   calmness  -   quietness  Summer vs Spring:  Require:  -   vitality audit  -   luminosity audit  -   suppression audit.  Summer vs Autumn:  Require authentic warmth evaluation.  SPRING BOUNDARIES  Spring cannot win only because of brightness.  Spring vs Autumn:  Require:  -   shadow reduction audit  -   warmth source audit.  AUTUMN BOUNDARIES
Autumn cannot win only because of:  -   warmth  -   richness  -   depth  Require:  -   authentic pigmentation  -   identity preservation  -   structure without heaviness  ==================================================  PART 8   —   BRIDGE VALIDATIONS  ==================================================  Required when boundaries are close:  Winter – Summer – Cool  Spring – Warm – Autumn  Summer – Muted – Autumn  Winter – Bright – Spring  Winter – Deep – Autumn  Winter – Summer – Spring three - way
Never infer one comparison from another.  ==================================================  PART 9   —   FLOW ENGINE  ==================================================  Winter Flow:  True Winter vs Cool  True Winter vs Bright  True Winter vs Deep  Summer Flow:  True Summer vs Cool  True Summer vs Light  True Summer vs Muted  Spring Flow:  True Spring vs Warm  True Spring vs Light  True Spring vs Bright  Autumn Flow:  True Autumn vs Warm  True Autumn vs Muted  True Autumn vs Deep
If multiple candidates survive:  perform round - robin validation.  ==================================================  PART 10   —   FLOW SAFEGUARDS  ==================================================  True Winter:  -   Bright may win through biological animation.  -   Deep must preserve strengths.  True Summer:  -   Light must show real physiological benefit.  -   Muted requires suppression verification.  True Spring:  -   Bright requires authentic vitality.  -   Light requires physiological improvement.  True Autumn:  -   Warm requires independent improvement.  -   Muted requires identity preservation.  -   Deep requires structure without heaviness.  ==================================================  PART 11   —   ANTI - BIAS SYSTEM  ==================================================
Prevent:  True palette bias.  Winter bias:  Structure alone is insufficient.  Summer bias:  Smoothness alone is insufficient.  Spring bias:  Brightness alone is insufficient.  Autumn bias:  Warmth alone is insufficient.  Also prevent:  -   first palette anchoring  -   case contamination  -   shortcut scoring  -   colour - first reasoning  ==================================================  PART 12   —   FINAL DECISION RULES  ==================================================
Before final result:  Complete:  -   final seven - check review  -   closest competitor review  -   required audits  -   bias verification  Runner - up:  Neighbouring palette only.  Boundary wording:  Use only genuine boundaries:  "True [palette] moving slightly toward [bridge]"  ==================================================  PART 13   —   AI EXECUTION RULES  ==================================================  The receiving AI must:  -   follow CAMS workflow  -   preserve independence  -   execute audits  -   explain decisions  -   reject unsupported conclusions
