# 02b_CAMS_v1_Project_Methodology_Export

CAMS AI PROJECT METHODOLOGY EXPORT v1.0  CORE KNOWLEDGE TRANSFER DOCUMENT  PURPOSE  This document contains the foundational CAMS AI methodology rules required to transfer the CAMS  colour analysis system into another AI platform.  This is the original methodology layer:  "What the AI must know."  It excludes:  -   client cases,  -   client images,  -   historical outcomes,  -   unavailable calibration examples.  The receiving AI must learn CAMS methodology, not memorize previous results.  ==================================================  1. CAMS SYSTEM SCOPE  ==================================================  CAMS is an evidence - based colour analysis system.  Primary evidence:  -   drape analysis only.
The AI must ignore:  -   previous analyses,  -   previous conclusions,  -   previous predictions,  -   answer pages,  -   highlighted answers,  -   expected seasons,  -   library conclusions.  Each person must be treated as a completely new case.  Do not use:  -   hair colour unless explicitly provided,  -   Fitzpatrick unless explicitly provided,  -   assumptions,  -   stereotypes.  ==================================================  2. APPROVED PALETTE SYSTEM  ==================================================  Only these palettes are used:  Home Seasons:
-   Winter  -   Summer  -   Spring  -   Autumn  Flow Palettes:  -   True Winter  -   True Summer  -   True Spring  -   True Autumn  -   Cool  -   Warm  -   Bright  -   Light  -   Deep  -   Muted  True palettes are candidates only.  A True palette is not automatically correct.  ==================================================  3. CAMS WORKFLOW  ==================================================
The system operates in two phases.  PHASE 1:  HOME SEASON  Determine:  -   Winter  -   Summer  -   Spring  -   Autumn  Required comparisons:  -   Winter vs Summer  -   Winter vs Spring  -   Winter vs Autumn  -   Summer vs Spring  -   Summer vs Autumn  -   Spring vs Autumn  Every comparison must begin from a neutral starting point.  Required sequence:  1. Observe Palette A.  2. Observe Palette B.
3. Compare using CAMS checks.  4. Verify from reverse order.  5. Reconcile differences.  Do not:  -   import previous comparisons,  -   use Flow results,  -   count wins mechanically.  PHASE 2:  FLOW  Only begin after Home Season.  Evaluate eligible Flow palettes equally.  ==================================================  4. SEVEN CAMS CHECKS  ==================================================  Every decision must use the seven CAMS checks.  1. FACIAL DETAILS  Evaluate:
-   under - eye effects,  -   eye socket effects,  -   cheek hollows,  -   mouth corners,  -   nasolabial areas,  -   jaw effects.  Distinguish:  Healthy anatomical modelling  from  Unhealthy shadow burden.  --------------------------------------------------  2. SKIN COLOUR  Evaluate:  Positive:  -   believable flesh colour,  -   healthy colour presence.  Negative:  -   grey veil,
-   white patches,  -   washed appearance,  -   yellow/sallow cast,  -   excessive redness.  --------------------------------------------------  3. SKIN CONSISTENCY  Evaluate:  -   whole - face pigmentation continuity.  Do not confuse:  -   smoothness with improvement.  --------------------------------------------------  4. JAWLINE  Evaluate:  -   support,  -   lift,  -   heaviness,  -   drag.
--------------------------------------------------  5. EYES  Evaluate:  -   authority,  -   animation,  -   vitality.  Eye strength cannot override poor complexion response.  --------------------------------------------------  6. FOCUS  Mandatory hierarchy:  Eyes → Person → Colour  The person remains the subject.  --------------------------------------------------  7. BALANCE/HARMONY  Evaluate:
-   integration,  -   palette support,  -   whether colour overwhelms the individual.  ==================================================  5. INTERPRETATION PRINCIPLES  ==================================================  Observation must happen before interpretation.  Separate:  1. Genuine physiological improvement.  2. Palette - created visual effects.  3. Uncertain effects requiring audit.  The AI must prioritize:  -   healthy facial response,  -   harmony,  -   person - first appearance.  ==================================================  6. GLOBAL AUDIT FRAMEWORK
==================================================  Required audit concepts:  Independent Physiology Audit:  Determine whether improvement is real facial improvement.  Effect Source Separation:  Separate physiological change from palette - created effect.  Natural Luminosity Audit:  Evaluate:  -   openness,  -   natural sheen,  -   eye vitality,  -   healthy colour activity.  Grey Veil / Suppression Audit:  Evaluate whether softness is harmony or suppression.  Authentic Pigmentation Source Audit:  Separate:
-   authentic pigmentation,  -   reflected colour,  -   redness,  -   yellow cast.  Complexion Physiology Priority Audit:  Before final decisions review:  -   shadow burden,  -   continuity,  -   believable flesh colour,  -   grey/white veil,  -   yellow cast.  ==================================================  7. ANTI - BIAS RULES  ==================================================  The AI must prevent:  True palette bias.  Winter bias:  Structure alone is insufficient.  Summer bias:  Smoothness alone is insufficient.
Spring bias:  Brightness alone is insufficient.  Autumn bias:  Warmth alone is insufficient.  The AI must always ask:  Does this improve the person?  ==================================================  8. FINALIZATION RULES  ==================================================  Before finalizing:  Complete:  -   CAMS check review,  -   closest competitor review,  -   required audits,  -   bias checks.  Runner - up:  Must be a neighbouring palette only.
Boundary wording:  Only for genuine boundaries.  Format:  "True [palette] moving slightly toward [bridge]"  ==================================================  9. AI TRANSFER REQUIREMENTS  ==================================================  The receiving AI must preserve:  -   CAMS methodology,  -   evidence rules,  -   workflow,  -   seven checks,  -   audit logic,  -   anti - bias protections,  -   decision principles.  The AI must not:  -   memorize client outcomes,  -   create shortcuts,  -   replace CAMS rules with assumptions.
END CAMS AI PROJECT METHODOLOGY EXPORT v1.0
