CAMS AI KNOWLEDGE BASE v13.0  BOUNDARY ENCYCLOPEDIA  DETAILED COMPARISON KNOWLEDGE SPECIFICATION  PURPOSE  This document expands CAMS boundary reasoning.  It defines:  -   common conflicts,  -   required audits,  -   valid evidence,  -   invalid shortcuts,  -   tie resolution principles.  Excluded:  -   client cases,  -   client images,  -   historical outcomes,  -   unavailable calibration examples.  ==================================================  1. BOUNDARY DECISION PRINCIPLES  ==================================================
Every boundary comparison must:  -   begin from neutral,  -   evaluate both candidates independently,  -   use seven CAMS checks,  -   identify physiological effects,  -   separate visual effects,  -   complete required audits.  Do not decide using:  -   palette reputation,  -   True palette status,  -   brightness alone,  -   warmth alone,  -   depth alone,  -   softness alone.  ==================================================  2. WINTER BOUNDARIES  ==================================================  WINTER VS SUMMER  Primary conflict:  Structure and definition versus physiology and softness.  Required audits:
-   shadow versus modelling audit  -   complexion physiology audit  -   grey veil audit  Winter requires:  -   healthy definition,  -   preserved complexion,  -   no excessive colour pressure.  Summer requires:  -   reduced unhealthy shadow,  -   preserved facial information,  -   believable colour.  Invalid:  Winter wins only because it looks sharper.  Summer wins only because it looks smoother.  --------------------------------------------------  WINTER VS SPRING  Primary conflict:  Refinement versus vitality.  Required audits:  -   physiology - first audit
-   healthy colour activity audit  -   natural luminosity audit  Spring can win when:  -   colour activity improves,  -   luminosity improves,  -   face appears more alive.  Invalid:  Winter winning only through cleanliness or organization.  --------------------------------------------------  WINTER VS AUTUMN  Primary conflict:  Cool structure versus warm pigmentation.  Required audits:  -   authentic pigmentation audit  -   colour pressure audit  -   heaviness audit  Autumn requires:  -   believable warmth,  -   integration,  -   vitality.
Winter requires:  -   no white/grey veil,  -   no unhealthy shadow burden.  ==================================================  3. SUMMER BOUNDARIES  ==================================================  SUMMER VS SPRING  Primary conflict:  Suppression versus authentic vitality.  Required audits:  -   luminosity audit  -   smoothness source audit  -   vitality integration audit  Summer advantage:  Only valid if harmony is genuine.  Spring advantage:  Valid when vitality improves without patchiness.  Invalid:  Summer wins only because skin appears smoother.
--------------------------------------------------  SUMMER VS AUTUMN  Primary conflict:  Cool refinement versus authentic warmth.  Required audits:  -   authentic warmth audit  -   pigmentation audit  -   anti - Summer bias audit  Summer cannot win only because it appears quieter.  Autumn cannot win only because it appears richer.  ==================================================  4. SPRING BOUNDARIES  ==================================================  SPRING VS AUTUMN  Primary conflict:  Vitality versus grounding.  Required audits:
-   shadow reduction audit  -   warmth source audit  -   vitality versus grounding audit  Spring requires:  -   healthy colour activity,  -   openness,  -   luminosity.  Autumn requires:  -   authentic warmth,  -   integration,  -   structure.  Invalid:  Autumn wins only through depth.  Spring wins only through brightness.  ==================================================  5. FLOW BOUNDARIES  ==================================================  TRUE WINTER VS COOL  Conflict:  Intensity versus moderation.
Required:  -   physiology preservation audit.  Cool cannot win only through refinement.  --------------------------------------------------  TRUE WINTER VS BRIGHT  Conflict:  Authority versus animation.  Required:  -   biological animation audit  -   eye hierarchy separation audit  Bright may win when:  -   eyes animate,  -   face becomes more alive.  --------------------------------------------------  TRUE WINTER VS DEEP  Conflict:  Depth versus preserved structure.
Required:  -   shadow burden audit  -   heaviness audit  Deep must not create drag.  --------------------------------------------------  TRUE SUMMER VS COOL  Conflict:  Soft definition versus calm structure.  Required:  -   structural definition audit  -   physiology audit  Definition must be beneficial, not assumed.  --------------------------------------------------  TRUE SUMMER VS LIGHT  Conflict:  Softness versus luminosity.  Required:
-   Light boundary physiology audit  Light must show:  -   improved continuity,  -   reduced unhealthy shadow.  --------------------------------------------------  TRUE SUMMER VS MUTED  Conflict:  Harmony versus suppression.  Required:  -   suppression audit  Muted must preserve facial information.  --------------------------------------------------  TRUE SPRING VS WARM  Conflict:  Vitality versus warmth.  Required:  -   authentic warmth audit
Warm must improve physiology.  --------------------------------------------------  TRUE SPRING VS LIGHT  Conflict:  Luminosity versus dilution.  Required:  -   flattening audit  -   grey veil audit  Light must not suppress.  --------------------------------------------------  TRUE SPRING VS BRIGHT  Conflict:  Vitality versus intensity.  Required:  -   biological animation audit  Bright may win through genuine animation.
--------------------------------------------------  TRUE AUTUMN VS WARM  Conflict:  True Autumn identity versus increased warmth.  Required:  -   independent improvement audit  --------------------------------------------------  TRUE AUTUMN VS MUTED  Conflict:  Richness versus softness.  Required:  -   pigmentation magnitude audit  -   identity preservation audit  -   colour concentration audit  --------------------------------------------------  TRUE AUTUMN VS DEEP
Conflict:  Structure versus heaviness.  Required:  -   authentic structure audit  Deep must preserve vitality.  ==================================================  6. Review identity preservation.  4. Use cumulative evidence.
