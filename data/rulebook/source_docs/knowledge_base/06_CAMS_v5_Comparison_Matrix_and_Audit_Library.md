# 06_CAMS_v5_Comparison_Matrix_and_Audit_Library

CAMS AI KNOWLEDGE BASE v5.0  COMPARISON MATRIX & COMPLETE AUDIT LIBRARY  AI TRAINING TRANSFER DOCUMENT  PURPOSE  This document adds comparison - level intelligence to the CAMS AI knowledge base.  It defines:  -   comparison - specific safeguards,  -   required audits,  -   valid evidence,  -   invalid decision shortcuts,  -   tie resolution principles.  Excluded:  -   client cases,  -   client images,  -   historical outcomes,  -   unavailable calibration examples.  ==================================================  SECTION 1   —   COMPARISON RULE PRINCIPLES  ==================================================
Every comparison must:  1. Start from neutral.  2. Evaluate each palette independently.  3. Apply the seven CAMS checks.  4. Separate physiology from visual effects.  5. Complete required audits.  6. Verify from reverse order when required.  No comparison may be decided by:  -   palette reputation,  -   stereotype,  -   True palette status,  -   brightness alone,  -   warmth alone,  -   depth alone,  -   smoothness alone.  ==================================================  SECTION 2   —   HOME SEASON COMPARISON MATRIX  ==================================================  WINTER VS SUMMER  Primary conflict:  Definition versus physiology.
Required audits:  -   Winter neutrality audit  -   shadow versus structure audit  -   complexion physiology audit  Winter advantages require:  -   healthy modelling,  -   preserved complexion,  -   maintained harmony.  Summer advantages require:  -   reduced unhealthy shadow,  -   preserved facial information,  -   believable colour.  Invalid evidence:  -   Winter winning only from contrast.  -   Summer winning only from smoothness.  ==================================================  WINTER VS SPRING  Primary conflict:  Structure/refinement versus vitality/luminosity.  Required audits:
-   physiology - first audit  -   healthy colour activity audit  -   natural luminosity audit  Spring may win when:  -   colour activity improves,  -   luminosity improves,  -   shadow burden decreases.  Winter cannot win only through:  -   cleanliness,  -   refinement,  -   organization.  ==================================================  WINTER VS AUTUMN  Primary conflict:  Cool structure versus warm pigmentation.  Required audits:  -   colour pressure audit  -   authentic pigmentation audit  -   heaviness audit  Autumn requires:
-   believable warmth,  -   integration,  -   preserved vitality.  Winter requires:  -   no white veil,  -   no excessive shadow,  -   no complexion decline.  ==================================================  SUMMER VS SPRING  Primary conflict:  Suppression versus authentic vitality.  Required audits:  -   natural luminosity audit  -   smoothness source audit  -   vitality integration audit  Summer cannot win only through:  -   calmness,  -   softness,  -   smoothness.  Spring cannot win only through:
-   brightness.  ==================================================  SUMMER VS AUTUMN  Primary conflict:  Cool refinement versus authentic warmth.  Required audits:  -   authentic warmth audit  -   baseline skin integration audit  -   anti - Summer bias audit  Summer cannot win simply by appearing:  -   smoother,  -   quieter,  -   cooler.  ==================================================  SPRING VS AUTUMN  Primary conflict:  Vitality versus grounding.  Required audits:
-   shadow reduction audit  -   warmth source audit  -   vitality versus grounding audit  Autumn cannot win only from:  -   richness,  -   depth,  -   warmth.  Spring cannot win only from:  -   brightness.  ==================================================  SECTION 3   —   WINTER FLOW COMPARISONS  ==================================================  TRUE WINTER VS COOL  Audit:  Moderation versus preservation.  Cool requires:  -   physiological benefit.  Cool cannot win only through:  -   clarity,  -   refinement,
-   reduced intensity.  TRUE WINTER VS BRIGHT  Audit:  Biological Animation Audit.  Bright may win when:  -   eyes animate,  -   face becomes alive,  -   vitality increases.  Winter cannot win only through:  -   authority,  -   contrast.  TRUE WINTER VS DEEP  Audit:  Depth Preservation Audit.  Deep must preserve:  -   facial structure,  -   vitality,  -   harmony.  Reject:
-   heaviness,  -   drag,  -   shadow burden.  ==================================================  SECTION 4   —   SUMMER FLOW COMPARISONS  ==================================================  TRUE SUMMER VS COOL  Audit:  Structural Definition versus Physiology.  Definition is neutral until proven beneficial.  TRUE SUMMER VS LIGHT  Audit:  Light Boundary Physiology Audit.  Light requires:  -   improved continuity,  -   reduced unhealthy shadow,  -   genuine benefit.  Softness alone is insufficient.
TRUE SUMMER VS MUTED  Audit:  Suppression Boundary Audit.  Muted must prove:  -   harmony,  not merely reduced colour.  ==================================================  SECTION 5   —   SPRING FLOW COMPARISONS  ==================================================  TRUE SPRING VS WARM  Audit:  Authentic Warmth Audit.  Warm requires:  -   genuine improvement,  not colour addition.  TRUE SPRING VS LIGHT  Audit:  Luminosity versus dilution.
Light must not:  -   flatten,  -   grey,  -   suppress.  TRUE SPRING VS BRIGHT  Audit:  Physiology Separation Audit.  Bright may win when:  -   animation improves,  -   vitality improves.  ==================================================  SECTION 6   —   AUTUMN FLOW COMPARISONS  ==================================================  TRUE AUTUMN VS WARM  Audit:  Independent Improvement Audit.  Warm must provide:  -   more than visible warmth.  TRUE AUTUMN VS MUTED
Required audits:  -   authentic pigmentation magnitude audit  -   identity preservation audit  -   colour concentration audit  Muted cannot win only by reducing intensity.  TRUE AUTUMN VS DEEP  Audit:  Authentic Structure Audit.  Deep must avoid:  -   heaviness,  -   drag,  -   loss of vitality.  ==================================================  SECTION 7   —   ADDITIONAL CROSS - COMPARISON RULES  ==================================================  BRIGHT VS COOL  Required:  -   animation audit  -   clarity versus vitality audit
Bright requires:  genuine biological animation.
