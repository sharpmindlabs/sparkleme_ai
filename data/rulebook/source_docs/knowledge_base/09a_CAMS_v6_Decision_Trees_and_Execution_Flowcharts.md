# 09a_CAMS_v6_Decision_Trees_and_Execution_Flowcharts

CAMS AI KNOWLEDGE BASE v6.0  DECISION TREES AND EXECUTION FLOWCHARTS  AI EXECUTION SPECIFICATION  PURPOSE  This document converts CAMS methodology into sequential execution logic.  The purpose is to allow another AI system to execute CAMS analysis consistently.  Excluded:  -   client cases  -   client images  -   historical outcomes  -   unavailable calibration examples  ==================================================  FLOW 1   —   MASTER ANALYSIS EXECUTION  ==================================================  START  ↓  Reset Case
Check:  Is previous analysis information present?  YES:  Ignore and restart.  NO:  Continue.  ↓  Validate Evidence  Check:  Are approved drape inputs available?  NO:  Request required evidence.  YES:  Continue.  ↓  Begin Home Season  Do not open Flow.  ↓
Complete six Home Season comparisons.  ↓  Run required validations.  ↓  Finalize Home Season.  ↓  Open eligible Flow page only.  ↓  Evaluate Flow candidates equally.  ↓  Complete Flow audits.  ↓  Final seven - check audit.  ↓  Generate result.  ==================================================  FLOW 2   —   COMPARISON EXECUTION TREE  ==================================================
For every comparison:  START  ↓  Neutral reset  ↓  Observe Palette A  Record:  -   Facial Details  -   Skin Colour  -   Skin Consistency  -   Jawline  -   Eyes  -   Focus  -   Balance  ↓  Observe Palette B  Record same seven checks.  ↓  Compare
Ask:  Which palette improves physiology?  If unclear:  Run required audits.  ↓  Reverse order verification.  ↓  Reconcile.  ↓  Decision.  ==================================================  FLOW 3   —   PHYSIOLOGY DECISION TREE  ==================================================  Question:  Does the palette improve the person?  YES:  Continue evaluation.
NO:  Reject advantage.  Question:  Is improvement physiological or visual?  Physiological:  Give decision weight.  Visual only:  Do not allow to dominate.  Uncertain:  Trigger audit.  ==================================================  FLOW 4   —   SHADOW DECISION TREE  ==================================================  Observation:  More definition appears.  Question:  Is this healthy modelling?
YES:  Potential advantage.  NO:  Classify as shadow burden.  Question:  Does the face retain information?  YES:  Continue.  NO:  Reject effect.  ==================================================  FLOW 5   —   COLOUR DECISION TREE  ==================================================  Observation:  Colour appears stronger.  Question:
Is colour believable flesh colour?  YES:  Positive evidence.  NO:  Check:  -   redness  -   yellow cast  -   colour pressure  -   reflected colour  Reject if palette - created.  ==================================================  FLOW 6   —   LUMINOSITY DECISION TREE  ==================================================  Trigger:  Spring, Light, Bright, luminosity competition.  Ask:  Does the face show:  -   openness?
-   natural sheen?  -   eye vitality?  -   healthy colour activity?  YES:  Luminosity improvement.  NO:  Brightness alone is insufficient.  ==================================================  FLOW 7   —   SUPPRESSION DECISION TREE  ==================================================  Trigger:  Summer, Muted, softer palettes.  Ask:  Is smoothness caused by:  A. Harmony?  or  B. Reduced facial information?
If B:  Do not reward.  ==================================================  FLOW 8   —   HOME SEASON DECISION TREE  ==================================================  After six comparisons:  Ask:  Is one season consistently stronger physiologically?  YES:  Select Home Season.  NO:  Run:  -   bridge validation  -   cumulative physiology audit  If unresolved:  Carry candidates forward where allowed.  ==================================================  FLOW 9   —   FLOW DECISION TREE  ==================================================
Eligible candidates only.  Ask:  Does True palette win?  YES:  Require evidence.  NO:  Allow bridge palette.  Ask:  Are multiple candidates close?  YES:  Run round - robin validation.  NO:  Finalize.  ==================================================  FLOW 10   —   ANTI - BIAS DECISION TREE  ==================================================
Before final answer ask:  Did Winter win only because of structure?  If YES:  Re - audit.  Did Summer win only because of smoothness?  If YES:  Re - audit.  Did Spring win only because of brightness?  If YES:  Re - audit.  Did Autumn win only because of warmth/depth?  If YES:  Re - audit.  ==================================================  FLOW 11   —   FINAL OUTPUT TREE  ==================================================  Before release:
